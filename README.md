# FUTURE_DS_01
# Business Sales Performance Analytics

## Project Overview
This project analyzes Superstore sales data to identify sales trends, 
top-performing products, categories, and regions.

## Tools Used
- Microsoft Excel
- Power BI

## Dataset
Superstore sales dataset.

## Project Work
- Data cleaning and preparation
- Sales analysis
- Monthly sales trend analysis
- Category-wise sales analysis
- Region-wise sales analysis
- Customer-wise sales analysis
- Interactive Power BI dashboard

## Dashboard
The Power BI dashboard presents key sales metrics and business insights.

## Conclusion
This project helps understand sales performance and supports better 
business decisions.
